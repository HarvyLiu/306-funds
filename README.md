# 班費收支帳本

這是一套供班級總務在單一電腦記錄班費的終端機帳本。交易資料存放在 `data/transactions.csv`，公開報表由相同資料產生；程式不會自動執行 Git 指令。

## 安裝與初始設定

需要 Node.js 22 以上版本。在專案根目錄安裝鎖定的套件：

```bash
npm install
```

啟動帳本：

```bash
npm run ledger
```

第一次啟動會依序詢問目前學期、目前總務名稱與另一位總務名稱。輸入後按 Enter 繼續。初始設定完成後會在 `.local/` 留下本機標記；這個目錄不會提交到 Git。

舊版 `schema_version: 1` 設定仍可載入；下次變更並儲存任何設定時，帳本會改以 `schema_version: 2` 儲存。請在帳本設定畫面管理學期鎖定。

開始記帳時，先按 `a` 新增一筆收入，分類選 `期初餘額`，金額填入紙本帳簿目前餘額。CSV 只存正整數金額，收入或支出由交易類型決定。

## 日常操作

總覽畫面的按鍵如下：

- `↑`、`↓` 或 `j`、`k`：選取交易。
- `a`：新增交易；依序填寫日期、項目、分類、類型、金額、經手人、學期與備註，再按 `y` 確認或按 `n`／Esc 取消。
- `e`：編輯目前選取的交易，確認前不會寫入檔案。
- `d`：刪除目前選取的交易；必須按 `y` 再次確認。
- `f`：依學期、經手人、分類與類型篩選；各欄選 `全部` 可清除該條件。
- `/`：搜尋項目與備註；在總覽按 Esc 可清除搜尋文字。
- `s`：新增學期、經手人與分類，設定目前學期與預設經手人，調整學期順序，管理學期鎖定，或封存未使用的選項。新增學期或經手人後，需另外設為目前值或預設值。永久刪除學期時，必須輸入完整學期名稱確認。被交易引用的選項，以及目前預設值，不能直接封存。
- `p`：重新載入資料並執行發布前檢查，顯示交易筆數、總收入、總支出、總餘額與目前篩選小計。
- `r`：選擇交易或設定備份，先查看摘要，再按 `y` 還原；Esc 取消。
- `q`：離開帳本。

學期接續與鎖定規則：

- 學期依新增順序接續，選擇單一學期時會顯示唯讀的「期初結餘」。
- 先切換到下一個目前學期，再鎖定已完成的學期。
- 鎖定後仍可查看資料，但不能新增、修改或刪除該學期交易。
- 解鎖不需要密碼；已鎖定學期必須先解鎖才能設為目前學期或封存。
- 可在設定中逐步把學期往前或往後移；期初結餘與圖表會依儲存的順序重新計算。
- 已鎖定學期或與它相鄰的交換必須先解鎖。
- 永久刪除不會刪除交易；目前、已鎖定或仍有交易的學期不能永久刪除。

支出會造成負餘額時，確認畫面會顯示警告。只有再次確認後才會儲存。

## 公開報表篩選與圖表

- 總餘額走勢顯示真實累計餘額；分類、經手人、類型與搜尋只標示相符節點，不會重算成局部餘額。
- 收入、支出圓餅圖與主要收支變動會套用目前全部篩選條件。
- 各學期收支長條會套用篩選條件，期初與期末結餘仍顯示實際餘額。
- 每張圖可展開資料表，在鍵盤、觸控或無法顯示圖表時查看相同數值。

## 檢查與發布

提交資料前，在專案根目錄執行：

```bash
npm run validate:data
```

確認輸出的交易筆數與金額後，手動提交並推送資料：

```bash
git add data
git commit -m "data: update class fund ledger"
git push
```

GitHub Actions 會先安裝套件、型別檢查、執行測試、驗證正式資料與執行瀏覽器測試，全部通過後才在 `main` 分支部署報表。第一次使用時，請到 GitHub 儲存庫的 **Settings → Pages → Build and deployment**，將 **Source** 選為 **GitHub Actions**。驗證失敗時不會覆蓋上一個可用的 Pages 版本。

## 備份與復原模式

每次儲存交易或設定前，程式會把前一版放在 `.local/backups/transactions.csv` 或 `.local/backups/settings.json`。還原時會交換目前檔案與備份，因此誤還原後可再次執行還原來復原。

若 CSV 或設定檔無法解析，帳本會進入唯讀復原模式，顯示資料來源、列數或 JSON 路徑、欄位與原因。此時可按 `l` 重新載入、按 `r` 檢查並還原備份，或按 `q` 離開；新增、編輯、刪除與設定寫入都會停用。

## 公開資料與隱私

**交易項目、備註、經手人、金額與所有設定會出現在 Git 儲存庫及公開報表。請勿輸入學生姓名、個人資料或不適合公開的內容。**

第一版不記錄個別學生繳費狀態，也不儲存收據、照片或其他附件。

## 開發檢查

```bash
npm run typecheck
npm test
npm run validate:data
npm run build
npm run test:e2e
```

Playwright 測試會建立正式靜態報表，並在桌面、手機與響應式邊界檢查篩選、排序、圖表像素、表格捲動與畫面重疊。
